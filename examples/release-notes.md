# A little context, before the content.

Your document's metadata belongs right beside it. KarmDown displays simple frontmatter as a readable panel, while the source remains ordinary Markdown.

## What's in this release

- **Search** through the rendered document.
- **Live reload** with protection for edited drafts.
- **HTML export** with bundled math fonts and rendered diagrams.
- **Print / PDF** with a clean document layout.

> [!NOTE]
> Metadata is displayed as text. KarmDown does not execute YAML tags or scripts.

## Keep your documents portable

Use `title`, `author`, `date` and `tags`, or bring your own keys. Nested values stay literal. Your files remain useful in any Markdown editor.
